# Research basis and limits

This skill transfers the review method and diagnostic questions from the
author's documentation-for-agents research and preserved DocGen evaluation
materials. It does not claim that these studies validate a universal score.
The instructions are self-contained: reviewing a document does not require
the original research workspace, its models, internal sources or runners.

## Three different objects

1. **Representation:** how the same knowledge is arranged or expressed.
2. **Knowledge quality:** necessary facts, correctness, conditions and conflicts.
3. **Application:** whether a reader/agent produces the correct action or artifact.

These need separate evidence. Adding a missing restriction changes knowledge;
moving an existing restriction changes representation. A costly reading is not
necessarily an incorrect one. The primary external criterion in the research
is task success, with costs as secondary outcomes.

## Knowledge transferred from DocGen

| Preserved knowledge | Consequence for this skill |
| --- | --- |
| Atomic facts with necessity, conditions, criticality and pinned sources | A completeness finding must explain the reader need and source basis |
| Six domains of rubric review | Check activation/defaults, configuration, result, boundaries, interactions, compatibility |
| Required facts and all written claims are separate | Full coverage cannot hide an invented option; truthful claims cannot hide an essential omission |
| Before/after code and documents; retained claims and error origins | Separate introduced, inherited, outdated and uncertain errors |
| Conditions such as missing versus false, root versus nested, distinct fallbacks and historical state | Probe real behavior instead of accepting keyword matches |
| Independent rubric, internal critic and fast literal checks have different inputs and gates | A critic consuming generator analysis is not a blind independent authority |
| Quotes checked against snapshots can still be semantically insufficient | Verify both quotation accuracy and what the source establishes |
| Correct, incorrect-default, omitted-default, invented-option, paraphrase, retained-error and removed-error controls | Test both missed defects and false positives; recheck old knowledge |
| Raw judge verdict, normalized verdict and overall process result can disagree | State the layer and inspect actual issues/unknowns |
| Model-built rubrics, human-accepted PRs and repaired patches lack automatic gold status | Review necessity and semantic correctness independently |
| Repeated variants of one PR, reused controls and mixed evaluator versions | Do not treat them as independent held-out validation |
| No independently labeled real no-update corpus in the preserved pilots | An unchanged-candidate control is useful, but does not establish false-update rates in real projects |
| Missing fields, preparation failures and unresolved items | Unknown evaluation quality is distinct from bad documentation |

The preserved corpus is useful development material, not an independently
human-labeled validation set. Public availability of a source does not itself
grant permission to redistribute its text. This package transfers generalized
methods rather than copying internal PRs, raw agent logs or external corpora.

## Experimental families and practical limits

The series labels identify provenance, not a rank or a claim of independent
replications. Historical reports, audits and later syntheses have unequal
completeness. No old numerical effect is reproduced here as a validated weight.

| Series | Transferable diagnostic knowledge | Limit retained |
| --- | --- | --- |
| E1–E2 | Locality, named mappings, tables/prose and structure | Few observations; representation, length and delivery can be confounded |
| E3, E12 | Explicit final states and derived consequences, K01 | A strong local chain effect does not establish every derivation needs a summary |
| E4 | Shared/local applicability qualifiers, K04 | Reduced Input does not prove that a shared qualifier harms correctness |
| E5 | Positional versus keyed values, K03 | Cost and mapping errors differ; limited domain and repetitions |
| E6, E13, E19 | Numeric representation and interface compatibility, K02 | Large conversions without tools do not generalize to small thresholds or tool-equipped readers |
| E7 | Normative order and negation, K05/K06 | Distinct interventions and model-dependent directions |
| E8 | Explicit decision procedures, K09 | No established general advantage of procedural wording |
| E9, E11 | Local classification of examples, K22 | Removing redundant labels can reduce input while answers remain correct |
| E10, E15, E17 | Alias/canonical-name chains, K07 | Cost effects do not establish a universal correctness penalty; historical mappings are incomplete |
| E14, E16, E18 | Broader mechanism banks and transfer attempts | Missing historical protocols, technical gaps, ceiling and isolated errors restrict reconstruction |
| E20–E21 | Systematic condition, scope, navigation and presentation bank; repeats, K12 | No universal ranking; model dependence, multiplicity, technical missingness and Input-driven cost |
| E22 | Display order versus explicit normative first-error precedence, K05 | Narrow synthetic domain and procedure/model dependence; not every unsorted table is defective |
| E23 | Real local documentation fragments and boundary application | High baseline accuracy; ready context did not test navigation |
| E24 | Searching and applying real documentation | Available reporting lacks separate raw/usage records for a full independent audit |
| E25 | Wider real-document cases and failure taxonomy | Audit rejected cost-only historical classifications; lost context and off-target errors confounded apparent effects |
| E26 | A separated secondary FIFO rule, K08 | Different series, noise and isolation problems; no established general locality effect |
| E27 | Normalized K01–K24 across real documentation | Ceiling and ambiguous references; most reliable cost signals concerned Input; no validated weights |
| E28 | Real agent code tasks, retrieval, test gaps and provenance | Frozen PASS missed posthoc defects; protocols, interface confounds, semantic closure and criterion exposure limit causality |

The 24 normalized criteria are not all possible factors, nor proven mutually
independent mechanisms. The presentation reference retains the new and
ambiguously mapped extended questions C46/C47/C48/C50/C52/C53/C74/C84/C86/C88/
C95/C96/C97/C98. C99/C100 are content changes, not equivalent presentation
variants. An absent mechanism is inapplicable;
an untested mechanism is not a negative result. The older 35- and 100-item
banks do not become equivalent numbers of independently validated criteria.

## Maintaining the evidence boundary

The series labels identify the author's research, not public scientific
citations or independently reproducible benchmark results. All operational
instructions are contained in this package; the original workspace is not
needed to apply them.

No complete re-audit of every historical run is implied. When new evidence
changes a criterion, update its question and evidence boundary together.
An external claim about a product still needs that product's relevant source,
not this research summary.
